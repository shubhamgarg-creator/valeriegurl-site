Valerie Gurl V26 - Every Text Position Studio

Base: V25 unchanged except isolated addition of editor import, Firebase listener, and editor UI.

Admin: login, click floating Edit All Text Positions button, then click any text.
Customize X/Y, font size, colors, alignment, letter spacing, font weight, opacity. Save to Firebase at valerie_site/textPositionStudio.
Default: no overrides, original V25 visual positions remain unchanged.

IMPORTANT LIMITATION: text targets use DOM structural selectors; conditional rendering, inserted/reordered elements, or content restructuring can alter selector identities. For production-grade permanent IDs, add stable data attributes to every individual React text component.
