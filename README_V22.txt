Valerie Gurl V22 — Moonwalk Dancer Extension

Based on the supplied V21 source. Existing App.jsx functionality and configuration retained.

New features:
- Original SVG fedora dancer silhouette with moonwalk-inspired motion
- Moves left-to-right by default, direction configurable
- Enabled by default; admin can toggle independently of snowfall and twinkling
- Controls: color, opacity, size, speed, direction, vertical placement
- Existing Firebase backgroundEffects save/load handles all new keys
- Existing effects panel live-preview behavior preserved
- Respects reduced-motion operating-system preferences
- No external images, GIFs, music, or video assets needed

Open Host Login > Admin Dashboard > Animations, Snowfall & Dancer.

Run: npm install && npm run build && npm run dev
