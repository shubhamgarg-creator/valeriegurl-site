# VALERIE GURL - Sunday City Waves Website

Website for **VALERIE GURL** (The OG Party Host for Sunday City).

## Features
- Custom Dark Theme with Glowing Pink Accents
- Profile & Live Stats Counter (2,130+ Waves Hosted)
- Wave Booking Form (Gems Calculator + Proof Upload)
- Admin Command Center for Managing Registrations
- Direct Discord Integration

## Setup & Deployment
1. Upload code to GitHub.
2. Deploy to Vercel or Hostinger.
3. Add custom domain `valeriegurl.site`.
